Welcome to Bloxcraft

Explore four biomes, craft tools and building materials, and watch the world turn from day to night.

SMP requires a running Bloxcraft Node/WebSocket server. GitHub Pages alone hosts only the single-player website.

World changes and inventory are saved in this browser. Multiplayer worlds are shared while their server is online.

Crafting

Recipes use a 3×3 crafting grid. Press C or Esc to close.
